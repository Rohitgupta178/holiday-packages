# WanderNest Travels

A responsive holiday packages website built using Python, Flask, HTML, CSS, JavaScript, and SQLite.

## Features

- Responsive navigation
- Hero section
- About Us section
- Holiday package cards
- Contact form
- Server-side form validation
- SQLite contact storage
- Success and error pages
- Mobile navigation

## Technology Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite
